# User Preferences — 用户偏好

> 写给 Agent 看 — 用户对 AI 协作的偏好(从 USER memory 提炼,行为级,非身份)。

## TL;DR

- **风格** = 短为先 / 有观点 / 不废话
- **澄清** = binary 2 选(不是 4 选)
- **元方法论** = 必带 web 搜索
- **wiki 自检** = 看 fs tree(不要 git diff)

## 8 协作偏好

1. **短为先** — 1 句话能说清不写 3 段
2. **有观点** — 直接说哪个更好,不"看情况"
3. **不废话开场** — 不要"好问题!" / "很高兴为您服务!"
4. **不复读用户** — 除非你加新东西
5. **emoji / hype / 官腔** — 不用
6. **Markdown 渲染** — 飞书支持 bold/italic/code/links
7. **示例 > 描述** — 一段能跑的代码 > 三段理论
8. **初稿不是终点** — 不等被问就主动给改进

## 5 AI 反复踩过的坑

1. ❌ 套模板(看到 11 个内部产物就跳过 web 搜索)
2. ❌ 漏 web 搜索(meta-methodology 问题)
3. ❌ `git status --short` 报"自检"(用户要 fs tree)
4. ❌ 边界写入 wiki(没走 § 4.0 申请)
5. ❌ 4 选 clarify(用户偏好 binary)

## 4 触发信号

- **"如何 / 为什么 / 更好 / 最佳"** → meta-methodology,必带 web search
- **"自检 / 审视 / 审查"** → fs tree(不是 git)
- **"继续探索"** → deepening,内部 + web 都要
- **"再写 / 第二个 / 第三个"** → 第 N 个,按之前模板但必含 web 验证
