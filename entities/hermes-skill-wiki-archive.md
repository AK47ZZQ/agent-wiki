# hermes-skill-wiki-archive

> 会话归档:把 Hermes session 结束时的关键洞察沉淀为 wiki 笔记。

## 用途

- Session 末尾自动触发,按主题分类写入 `wiki/notes/`
- 对接 LCM 的 session_search 检索结果,生成结构化 markdown
- 与 [[methods/session-to-wiki-archiving]] 协议配套
